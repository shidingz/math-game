# 线上原版风格的主题特效

当前微信版本 `wechat-v21-effect-library`，效果版本 `website-themes-v2`。用户认可v20效果，本轮仅扩充图形库与自定义伙伴的搭配规则，保留当前背景、内置伙伴主题、体型、成长节奏及打招呼。v20曾以线上网页测试版 `https://shidingz.github.io/math-game/?test=1` 为美术参考。

已通过隔离浏览器实际访问线上页面，查看悟空、萨摩耶、暹罗猫、玉兔的1/6/11/15级。八位角色的公开特效/播放器源码与本地原版SHA256一致，因此本地源码可用于核对图形风格。线上旧版经济文案不是本次修改来源；当前200分兑换、30/100题进化和存档规则保持。

去掉整体彩带、串珠线、小粒子和粒子爆发。使用细轮廓与完整主题形状，缓慢浮动，全部放在宠物后面；前景绘制分支不产生像素。背景和双伙伴等大互动保持v19。

## 任意照片伙伴

`effect-motifs.js`是32种可复用Canvas图形：星芒、晶体、雪花、叶片、月牙、祥云、盾牌、莲花、火焰，以及蝴蝶、羽毛、花朵、花苞、四叶草、蕨叶、水滴、海浪、贝壳、珍珠、彗星、行星、太阳、极光、棱镜、冰锥、宝石、爱心、翅膀、旋纹、风铃、提灯、闪光。全部由程序路径绘制，没有新增贴图、网络请求或模型调用。

`pet-particles.js`沿用入口名，内部已没有粒子或彩带引擎。共有20套主题组合：原有8套，加花语、蝶舞、轻羽、四叶森语、潮汐、珍珠、彗星、星际、极光、晨曦、棱镜、灯火12套。

内置伙伴沿用原主题、配色、图形顺序和布局。新伙伴以**首阶段像素色调+稳定ID**选择兼容主题，再确定搭配图形、4种疏密相近的摆位、3种缓慢漂动方式。绿色偏花叶、蓝色偏水光冰晶、紫色偏月星、暖色偏晨光灯火；中性色从云、羽、冰、珠等组选择。同色宠物也有多种选择，刷新和进化保持选定主题与图形身份；当前阶段的色调可改变配色。19套通用主题可用于照片伙伴，盾徽仅保留给内置柯基，不根据照片臆测职业。

每次仍只绘制2–5个完整图形，不把32种同时堆在屏幕里。每个伙伴的候选来自兼容小组，数量与逐级增强规则保持v20；Lv.6添加主轮廓，Lv.11加强，Lv.15外观封顶。减少动态模式冻结所有图形。图形库可继续增补，不需要为每个伙伴生成代码。

`view.effectProfile()`缓存当前配色和首阶段baseHue/baseNeutral，以及伙伴ID与custom标志。特效尺寸跟随双人互动后的主宠位置，访客实际等级/阶段与左右等高布局保持。
