# 背景细节与规则动景

当前背景模块为 `wechat/runtime/kingdom-scenes.js`，版本 `toy-worlds-v3`。宠物几何与脚下位置不变，仍落在场景高度的 86.5%。

## 清晰度

上一版8幅背景先缩至256×256/格，手机扩大舞台后明显放大。现在从旧生成原图恢复443×443/格实际细节；新增8幅也保留443×443/格。4×2图集为1772×886，构建保持该尺寸，以JPEG质量78导出；不是把旧256图简单放大。取样向格内缩1像素，避免相邻场景的边缘串色。高DPI手机仍会放大位图，不能把这称为无限分辨率或真机已验收。

## 16种场景与48项素材

保留游乐场、木屋、巴士站、星空魔法屋、海滩、云端小屋、花园、车库。新增晚霞露营地、苹果野餐园、河畔小镇、月光露台、暖木图书室、海底观察室、玻璃花房、蜜桃烘焙屋。合计8室内、8室外，先按ID稳定种子等概率选室内外，再按宠物色调加权选对应场景；同一ID不会每帧或重开随机换背景。奇数数量的宠物不保证恰好一半。

图集组为：`skies`、`grounds`、`nature`、`landmarks`、`places`、`living`，每组8格，共48项。旧Q版特效图集不在当前CATALOG或微信构建引用中。新场景不再叠加地台，复用自带地面；旧场景原有活动垫保留。没有新增粒子底座。

6种侧边布局分别为左右角落、花园双角、远处玩具、窗边、开阔庭院。各布局使用2–3个侧边道具，中央留给伙伴；每场景最多2个缓慢动景，加最多1个低频穿行元素，不因升级堆满画面。

## 程序动画

新增风筝、风铃、纸飞机、热气球、叶枝、提灯、风车叶、帆船8个真实Alpha素材，分别作摆动、漂浮、旋转或摇摆。风车只旋转独立叶轮；风铃/提灯用细线悬挂，转子使用静态细杆。每27–35秒内最多有一段5秒的纸飞机/树叶穿行，只从画面顶部通过，不穿过宠物脸。`reducedMotion` 固定所有动景并取消穿行。

动景、配色、布局均本地计算，无运行时AI、命名或代码请求。玩家已解锁伙伴访客属于单独互动模块，本文件不选择、解锁或改变伙伴进化阶段。

## 素材来源与体积

最终文件在 `assets/toy-worlds/`：恢复后的 `skies.png`，新 `places.png`、`living.png`。本轮使用内置 imagegen：2次新素材请求，加1次把道具伪棋盘背景改为纯品红的编辑请求。最终Alpha由固定色键处理产生；首张未把伪棋盘当透明图导入。完整提示词在 `docs/prompts/world-refresh/`；生成过程及拼装检查在被忽略的 `artifacts/world-refresh-20260918/`。

新背景构建总计731,793字节，旧背景366,397字节，净增365,396字节。`scripts/build-kingdom-art.cjs` 验证背景至少400px/格、道具Alpha与4×2布局，再导出6张纹理。正式总包体以最终完整导出与微信工具的检查为准。

验证覆盖：16场景室内外分类、原生像素、48项可达、6种稳定布局、颜色匹配、动画变化、减少动态、穿行数量/区域、有效图集坐标与缺图回退。浏览器另有16场景拼装截图检查，真机清晰度仍需设备验收。
