## 新增或替换角色

1. 拟定三阶段（Lv.1—5、6—10、11+）和 15 级递增体型/特效，先确认静态方向。
2. 以同一参考形象生成一致的姿势，保留完整耳朵、尾巴、兵器和披风；独立 PNG 使用真实透明通道，不能把棋盘底当透明。
3. 按播放器要求拼图，统一足底锚点、视线、色彩、相对体型。写 data.js 的 frames、stages、levels、actions；程序特效放 effects.js。
4. 创建或复用对应播放器，实现统一适配器约定。食物动作保持 500ms，Lv.15 后使用最终外观，不限制存档等级。
5. 在 game/{id}-character.js 注册 food、unlock、ui、stages、effects、随机动作、messages 和 create。index.html 按依赖顺序引用，新 id 按 core.js 与恢复校验检查。
6. 更新 scripts/project.cjs 的 ids 与素材规则，运行 npm run assets；测试所有三阶段与手机全屏升级。

替换同路径图片时提升播放器 URL 查询版本，更新 index.html 的脚本版本，避免线上缓存旧图。独立 PNG 与图集必须一起更新；资源清单用于检测意外变化，不能证明图画本身审美或动画衔接正确，仍须视觉检查。

图像来自此前用户确认的 ImageGen 生成结果；本整理版保留最终成品，不含生成服务密钥、参考照片或原始提示词链。继续修改可直接使用最终单帧作为视觉参考，旧对话不是开发依赖。
