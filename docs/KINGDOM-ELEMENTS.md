## 组合和动画

- 从各阶段有效像素已有统计中取主色；中性色按210°冷色匹配。先按色相距离选协调主题和特效，再使用宠物ID作为随机种子挑选兼容的景物、位置和粒子。没有按角色名字判断，也不修改每只宠物的代码。
- 八类场景：晴空草甸、金色原野、澄蓝湖谷、星月遗迹、青碧海湾、晴光雪岭、森间秘境、霞光峡谷。每一类有适配的植被和建筑候选，不把所有景物同时塞进场景。
- 分层顺序：天空远景、地形、侧面建筑/植被、脚下阴影、法阵/觉醒轮廓/粒子、宠物。中心保留主体空间，特效不会覆盖宠物脸部。
- 相同ID/阶段/色调得到稳定组合；新增宠物ID自然产生新的组合。开发页“再组合一套”可改变变体种子，正式存档不因此改变。
- Lv.1已有小法阵和少量粒子；Lv.6出现大型觉醒轮廓；Lv.11增大并叠加辅助法阵；Lv.15增加顶部标记，尺寸、粒子数量封顶。喂养完成有短爆发；减少动态模式不播放漂浮、转动或爆发。
- 最大9个常态粒子，七张图集共享；尺寸、透明度、轻微旋转和漂浮均由Canvas程序驱动。上线时只有图片加载和规则绘制，不调用生成模型。

保留紧凑宠物框、逐级体型、78px主按钮、自定义改名、选择练习范围后返回主页、Lv.6/Lv.11进化题数说明以及所有经济/存档规则。

## 真实遇到的问题及处理

1. **假透明**：六张请求透明的原图均为RGB PNG，棋盘是画进去的。`prepare-kingdom-art.cjs`检测通道后用固定像素规则恢复Alpha。特效按中性灰色带去底、保留亮白核心；建筑/植被先识别局部交替灰白纹理，再处理其邻域，避免把白色花瓣和水晶切面全去掉。源PNG和报告如实标记`sourceAlpha:false`。
2. **网格偏差**：返回1774×887，且自然景物上下分界实际约y=480，并非等分的444。离线脚本在名义边界±15%内寻找透明占用最低的切线，然后每格归一化，防止邻格树叶串入。实际裁切矩形保存在`packing-report.json`。
3. **包体超预算**：首次把全部256px元素直接打包超过20MiB保守检查。最终天空用JPEG；透明景物/大特效导出为224px格，动态粒子仅128px格，PNG调色板压缩。原件仍保留256px格，宠物素材未降质/删减。
4. **小图集限制**：透明恢复是这套美术的离线规则，可能有少量边缘碎点/光晕损失；它不是任意照片的通用抠图承诺。宠物照片流水线没有因此改用灰色去底。
