# 固定生图与规则装配流程

当前默认入口是 `scripts/pet-alpha-pipeline.cjs`。每套宠物正常只需要四个 302.AI 图片任务：三阶段设定一张，以及三个阶段的动作图各一张。它没有聊天、命名、视觉质检、AI 抠图、AI 修图或代码生成步骤。三个动作请求使用对应的设定格，九个关键姿势按共享播放器播放，不是模型生成的骨骼动画。

## 固定的输入与输出

- 提示词保持 `alpha-original-v1`，没有本次兔子、毛色、物种或年龄专属文字。1—3 张用户图整理成主体参考板。三格和九格模板均为真正的透明 PNG，只有黑色辅助线。
- 画风参考现在默认萨摩耶三阶段待机图，纯像素裁切、拼接成参考板；`--style siamese` 可选择旧参考。参考角色只承担画风职责，提示词禁止照抄物种、服饰、动作与进化路线。
- 新包名称固定为「新伙伴」，不接受个性化 `--name`。任务第一次创建时用随机字节生成唯一 ID，恢复同一任务则沿用原 ID；因此同名伙伴可以独立成长和多次生成。客户端允许用户手动改名，别名单独保存在`customPetNames`，不修改素材包、不调用AI命名。
- 图像返回后按 [透明分格规范](ALPHA-PET-PIPELINE.md) 去线、分格、统一缩放、定位、生成头像与图集。异常保留原图与原因；不能分离的图不会自动写入游戏。格式检查不等于身体结构或相似度检查。
- `quality.json` 使用 `technical-checks-passed`，`semanticReview: not-performed`。本轮不做任何 AI 视觉质检，不声称算法保证所有未知图片都能正确生成。
- 配色使用透明待机图的有效像素直方图。当前背景和特效由56项Q版共享预制插画组成；图集在开发期一次性生成，运行时按色相/稳定种子选择兼容的景物与特效，程序负责分层和动画。规则不依赖宠物名称或单独编写代码。

```sh
# 仅准备模板与固定请求，不调用接口；环境中需配置已有 API302_API_KEY。
npm run pet:generate -- --out artifacts/my-job --photos /path/to/photo.png
# 自动运行，轮询原任务、下载、规则装配；可中断后执行相同命令恢复。
node scripts/pet-alpha-run.cjs --out artifacts/my-job --photos /path/to/photo.png
```

每个已确认 429/500/502/503/504 失败的任务至多重试一次，四步最多八次提交；未知 POST 结果、格式拒绝及重试额度耗尽会停止。不通过换模型或改提示词绕过失败。任务和归档失败次数计入日志。进程并发互斥、费用额度、订单权限、远端队列和完成通知仍应由正式服务端管理。

## 运行时调用面

| 环节 | 网络调用 | 额外 AI |
| --- | --- | --- |
| 微信登录会话 | 自有服务 `POST /session` | 无 |
| 照片上传 | 自有服务 `POST /pet-photos` | 无 |
| 创建任务、查询进度 | 自有服务 `POST/GET /pet-jobs` | 无 |
| 生成图片 | Worker → 302.AI `/v1/images/edits?async=true` | 仅生图 |
| 查询图片任务 | Worker → 302.AI `/async_result` | 无新增生成 |
| 命名、裁切、头像、颜色、背景、配置 | 普通代码 | 无 |
| 客户端获取新宠物 | 下载经过域名校验的图片与 JSON | 无 |
| 动作、喂养、升级、特效 | 已发布的共享 Canvas 代码 | 无 |

客户端中没有模型 API Key、模型地址或远程代码执行。`seedream-client.cjs` 目前还被默认 Worker 导入，但只复用 `settings/atomic` 配置和文件助手，未调用其中的 `generate`。旧 `pet:audit`、Seedream、旧网关脚本是独立开发工具，默认生成入口不会运行，也不进入微信包。以后部署只启动默认 Worker，不把历史开发命令接入订单处理。

`scripts/audit-pet-runtime.cjs <微信导出目录> <任务目录>` 检查实际发出的固定提示词与任务记录，并扫描客户端模型地址、密钥标识和动态代码。素材测试还将网络限制在图片提交/轮询路由，缓存恢复时禁用全部网络。静态扫描不是对未来任意修改的安全证明，应保留这些自动检查。

## 程序特效与历史预制素材

2026-09-18当前，默认微信渲染使用 `kingdom-scenes.js`组合56项预制插画，按颜色、稳定随机种子与等级搭配；旧矢量元素库不再默认调用。进化题数由只读规则计算；详见 [TOY-WORLDS.md](TOY-WORLDS.md)。运行时加载7个共享图集，不调用额外图像/文本模型。内置宠物的阶段颜色在导出时用像素直方图统计，生成宠物使用素材包原有配色数据。

旧 `assets/fantasy-scenes/` 五张图只作历史留存，新版导出不再打包。原始五次开发期imagegen记录与提示词仍保留，不代表上线会调用；不要把历史工具 `build-fantasy-scenes.cjs` 接回默认导出。

## 当前交付边界与后续优化

兔子已完整生成，测试包可玩；正式的上传生成服务、支付、云存档、队列和真实微信上线没有部署。不要把本机 Worker 或浏览器模拟称作已上线服务。

优先优化：服务端为订单加互斥锁与幂等键；同一照片、模板、模型和提示词版本可按哈希缓存；生成用图集按版本存对象存储并走 CDN，避免把每位用户的宠物塞进安装包；每个任务固定费用预算与重试上限。均不需要额外模型。

进一步可用普通算法处理动画间最大尺寸异常、透明边缘接触率、重复帧相似度等指标，并允许用户反馈不满意；这些只能发现部分异常，不能替代对动作合理性和身份相似度的语义判断。现阶段不加入额外 AI 检查。
