# 透明模板与容错裁切 v1

本版本按用户要求替代“模型必须像素级复刻辅助区”的验收思路。模板和请求明确要求透明 PNG，提示词严格规定尺寸、顺序和留白；接收时不因小幅尺寸、格线或角色位置偏差直接重画。整个规则在新任务提交前固定，模型生成之后只用普通像素算法，不调用 AI 抠图或为单只宠物写代码。

## 生成约定

- 302.AI `gpt-image-2.5-sunburst`，图片编辑请求使用 `background=transparent`、`output_format=png`。接口参数参考 [302.AI 编辑文档](https://doc.302.ai/288853817e0)。透明度是否真的返回必须检查文件，不能仅看扩展名或网页棋盘格。
- 三阶段设定：3072×1024，一行三列，每格四周要求96px空白；三阶段共享身份，但明显进化。
- 阶段动作：1536×1536，3×3；每格要求48px空白，九个姿势保持同一比例尺。进食方式自由；背景使用开发期预制库，远处动态特效由程序绘制。
- 输入模板是透明底的真正RGBA PNG，只画3px黑色外框和分界线。不画白底、绿底、棋盘格或内层彩色画框。
- 单张或多张用户参考使用同一提示词。主体不预设年龄或物种；插画等参考沿用通用原创替代规则，但不声称模型已完成权利判断。

## 裁切规则（所有主体共用）

源是PNG，单格至少240px；最大边8192、总像素2400万。只要透明背景真实存在且可分离，即可在原始分辨率处理，不为凑请求分辨率而拉伸。Alpha≤12的像素归零，其他透明边缘保留；不做色键抠图，因此绿色皮肤、白色毛发和黑色服装也保留。

在名义分界附近22%格宽的范围识别窄而连续的中性黑灰直线；删除已识别线及少量抗锯齿像素，不能把整条任意颜色像素带直接清空。靠近角色的线条接触会标记人工检查。清理极小孤立噪点后，在名义分界附近24%格宽范围寻找至少3px的真实透明间隙，先分行、再逐行分列，允许格线偏移或各行列宽稍有不同。切线记录在报告中。

无实际Alpha、相邻主体无法分离、空格或极小主体会停止并保留原图。图像外边缘贴边、辅助线接触主体会标记视觉检查；算法不声称能识别脚趾、尾巴或语义缺损，也不会补画。通过提取的九格使用同一缩放系数，最大包围框进入416×400，居中、脚底基准448，生成每格512的透明图集和头像。低矮睡姿不单独放大。最终格式保持`template-v1`，共享小游戏播放器无需改动。

同一响应的所有候选均保存，按返回顺序选择首个通过透明度及分离规则的结果，并记录其余拒绝原因。下载器的默认最后返回项不决定本流程最终用图。几何合格不代表美术最好；当前按用户要求不调用 AI 质检，实际效果交由用户体验。

## 执行与恢复

```sh
npm run pet:generate:alpha -- --out artifacts/new-alpha-pet --photos /path/to/input.png --id custom-example-alpha --name '新伙伴'
# 模板、实际提示词、输入和代码哈希已保存，尚未提交。
npm run pet:generate:alpha -- --out artifacts/new-alpha-pet --photos /path/to/input.png --id custom-example-alpha --name '新伙伴' --submit --stop-after design
# 不需要暂停时去掉 --stop-after；pending 时运行相同命令，只恢复原任务。
```

默认画风参考为萨摩耶三阶段，名称固定「新伙伴」，省略 --id 时按规则生成唯一编号。可用 `node scripts/pet-alpha-run.cjs --out … --photos …` 自动继续，明确429/5xx终止失败时每步最多重试一次。每套正常四个请求，失败不会无限重试或擅自切换模型。`recipe.json`锁定API适配器、提示词、裁切和配色规则；原图在各阶段目录，`conversion-selection.json`记录实际候选，`processed/*/layout-check.json`记录去线与切线，`candidate/`为游戏标准素材包。`quality.json`区分程序检查通过与未执行语义检查；服务端、支付与正式发布不因本地流程而自动完成。

旧灰底固定模板保留为`pet:generate:guided`，旧任务不自动套用新规则。当前离线用例覆盖线条偏移、越过名义切线但仍完整的尾部、白/黑/绿主体、半透明附属物、伪透明拒绝、粘连拒绝、多候选选择和禁止网络的缓存恢复。真实请求结果另见交接与任务日志。
