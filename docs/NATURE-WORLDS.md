# 程序自然场景（v3）

历史方案：用户已改选A幻境光场＋D元素觉醒，当前默认背景不调用本页自然元素库，库保留供后续复用。见[ELEMENTAL-AWAKENING.md](ELEMENTAL-AWAKENING.md)。

微信渲染由`wechat/runtime/scene-elements.js`提供56种Canvas元素，由`growth-effects.js`与宠物播放器统一组合。所有画面都是程序绘制，不调用生图、命名或视觉模型，不加载场景贴图；不会为新增宠物生成专属代码。

## 主题与组合

八类世界：林间微风、竹溪山岚、晴日果园、海风小岛、雪山极光、花野漫游、星河梦境、流金山谷。由宠物像素主色选择适合的主题集合，再用宠物ID稳定选择主题与侧景位置。主色参与花朵、水果、暖色细节配色，树木、天空和水面保留自然色语义。主题和颜色计算缓存于角色阶段配置，不会每帧随机。

场景分天空、远景、水域、侧景、地面、空中点缀六层；远景降低透明度，前后景使用不同尺度。图像始终在宠物身后，首页裁于圆角框内。

一级已有9个景物和2个漂浮元素；4、6、7、9、11、12、14、15级依次添景，漂浮元素每3级增一个，满级最多17个景物和6个漂浮元素。新增元素不重排旧元素，保证连续成长；15级后场景封顶。星环、晶体和光带继续按现有规则递增。减少动态时仍有完整静态场景，但关闭漂移和奖励绽放。

新的宠物素材依然只需标准图集和颜色数据。组合不推断物种、天气或用户身份，无语义模型。

## 更紧凑的展示框与按钮

`pet-geometry.home(height, character)`用三个阶段的待机边界计算可容纳的统一成年高度，由此限定展示框，不再把屏幕剩余空间全部填给舞台；同一宠物的框不随当前等级改变。最高350逻辑像素，小屏按可用高度收紧。继续保留Lv.1→15约1.85倍的体型增长、跨阶段单调待机高度和各姿势防裁切。

390×844样例：兔子框465→321px，满级待机约276.5px高，头顶留约30px，供跳动与完整轮廓显示。喂养/做题按钮60→78px；范围/换伙伴44→52px；成长卡48→60px；底部入口32→40px。成功提示仍在宠物脚下、成长进度上方，不遮按钮。

## 验收与复用

- `tests/scene-elements.test.cjs`：56种不同路径、所有条目可达、8主题15级有限增量、坐标有效、减少动态、无图像调用。
- `tests/growth-effects.test.cjs`、`check-pet-geometry.cjs`：体型与安全边界，真实13角色共99,684组合。
- `wechat-growth-smoke.cjs`：5屏幕、9等级、喂食、升级、边界和减少动态。
- `wechat-personality-smoke.cjs`：重命名、重开存档、选题回主页，以及13伙伴每一级身高递增。
- `wechat-worlds-smoke.cjs`：56元素展示、8类场景切换及浏览器绘制开销；读`WECHAT_REVIEW_BASE`选择预览地址。
- `artifacts/living-worlds-20260918/review/`：同一绘图代码的56元素清单、8世界展示和实际游戏试玩，可手动切换场景做开发对比；游戏仍自动搭配。

浏览器绘制耗时只记录JavaScript提交Canvas命令的开销，不代表手机帧率或GPU实际完成时间。微信真机输入、帧率、内存与长时间运行仍须验收。
