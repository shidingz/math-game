# 精卫接入验证

已验证正式版需手动消耗 500 积分兑换精卫；499 积分不可兑换，兑换成功只扣款一次。喂蓝莓饭团消耗 20 积分，只增加精卫成长。其他角色、题库、成长门槛继续使用共享规则。

测试版首次默认精卫、10,000 积分和全部角色解锁；旧测试存档补入新角色，保留积分与既有成长。手动测试锁定不会被刷新自动撤销。正式存档不会因此解锁角色。

自动测试：64 项通过，包含精卫组件、15 级成长特效、游戏交易与旧存档迁移，以及已有游戏和玉兔回归检查。

独立浏览器 profile 检查通过，无页面脚本错误或资源 404。覆盖 15 级、三阶段 12 种动作、点击互动、Lv.5 → Lv.6 喂养进化、答题衔接、四位角色切换、390px 手机布局、刷新持久化与正式/测试存档隔离，以及精卫独立素材预览页。

图片资源通过 RGBA 透明度、边缘留白、品红残留、无损 WebP 一致性与 SVG 语法验证；已目视检查三阶段动作总览、桌面/手机游戏截图和深浅背景边缘。

复现：在项目根目录运行本机 HTTP 服务，然后执行 tests/browser-jingwei.cjs（需 Playwright 与 Chrome）。详细结果见 jingwei-browser-verification.json。
