# 布偶猫 v2 · 霜华成长

三阶段：奶凶毛团（Lv.1–5）→ 傲雪伙伴（Lv.6–10）→ 霜瞳守护者（Lv.11+）。幼年保持已确认的奶凶表情，成年身形修长、眼神平和友好。白灰长毛、蓝眼、粉鼻和银蓝披肩保持统一。

## 资源与动作

每阶段9张透明姿势PNG，另有1536×1536图集和256×256头像。单格512×512，脚底锚点(256,470)。姿势顺序为idle、blink、wave、pet、feed、think、sleep、jump、skill。共12种动作入口，通过姿势切换、呼吸、位移和缩放实现；不是骨骼动画。

每隔10–18秒随机待机，点击随机互动。喂食500ms；全屏升级演出由游戏共用控制器处理。支持后台暂停和减少动态效果。

## 成长与接入

1–15级逐级变大，每一级保留之前的特效层并加入新的冰晶、星桥、流星、光幕、霜翼或星轨。15级以后继续升级，外形和特效保持最终状态。`assets/effects/` 为15份独立SVG，`ragdoll-effects.js` 为实时生成器。

保持原角色ID `ragdoll`，原养成进度继续使用。正式版可作为免费初始宠物；选择其他宠物开局后，布偶猫为300积分兑换。鲜鱼猫粮每碗20积分，增加20成长值。

`preview.html` 为完整图鉴；游戏入口为 `../../index.html`，开发测试为 `../../index.html?test=1`。

## 来源

内置ImageGen参考用户确认的修长友好版三阶段设计生成。原图和完整提示词保存在项目 `output/ragdoll-v2/`；原角色备份也在该目录。`scripts/build-ragdoll-v2.cjs` 使用Sharp提取透明图集并同步独立SVG特效。手机、电脑、首次领养及进化验证截图位于 `../../qa/starter-ragdoll/`。
