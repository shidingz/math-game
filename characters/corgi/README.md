# 警犬柯基角色包 v2

三阶段：见习小警员（Lv.1–5）→ 机敏巡逻员（Lv.6–10）→ 王牌汪队长（Lv.11+）。
橙白毛色、短腿大耳、藏蓝警服与黑色背心；幼犬戴小警帽，巡逻员增加对讲机，队长戴黑色护目镜。

## 素材和动作

三套1536×1536透明图集，单格512×512、脚底锚点(256,470)。共27张独立姿势，另有三张头像和15张独立SVG特效。动作包括待机眨眼、抬爪问候、蹭手、喂食、思考、睡觉、跳跃、守护；组件还通过姿势组合与位移支持陪伴、庆祝、小跑、进化。属于图片姿势配合程序动画，并非骨骼动画。

喂养保持500ms。随机待机与点击互动沿用游戏交互控制器，答题和弹窗时暂停，支持后台暂停及减少动态效果。

## 成长特效

每一级放大体形并增加一层背景元素，保留此前各层：
1. 报到爪印
2. 警星伴行
3. 巡逻双环
4. 追踪足迹
5. 见习徽光
6. 巡逻觉醒
7. 雷达扫描
8. 星点路标
9. 六盾巡游
10. 探照光束
11. 队长觉醒
12. 列阵守护
13. 银蓝护翼
14. 交织警轨
15. 王牌守护领域

视觉变化截至Lv.15，之后仍可升级并沿用最终外观。升级使用共用暗背景全屏展示。

## 接入与存档

保持角色ID `corgi` 和原存档结构，因此已有等级、成长、喂养次数和解锁状态继续使用。300积分兑换；鸡肉能量餐20积分，增加20成长值。其他角色与成长经济不变。

`../../game/corgi-character.js` 提供蓝盾主题、食物、台词与游戏适配；加载 data、effects、component 后可使用 `<corgi-game-pet level="6"></corgi-game-pet>`。
`preview.html` 展示15级成长和全部姿势。测试入口为 `../../index.html?test=1`，选择柯基犬。
