# 比熊犬角色包

三阶段：Lv.1–5 棉绒幼犬 → Lv.6–10 云朵伙伴 → Lv.11 起晴空守护者。
保留参考照片的圆头、垂耳、白色卷毛和黑眼睛，以蓝色头巾、围巾、云纹披肩体现成长。

## 资源

- `assets/stage-1.png` 至 `stage-3.png`：1536×1536 透明动作图集，每格512×512。
- 每阶段九张独立透明姿势：idle、blink、wave、pet、feed、think、sleep、jump、skill。
- `assets/stage-N-portrait.png`：角色头像。
- `assets/effects/level-01.svg` 至 `level-15.svg`：15级可叠加的矢量背景特效。
- `bichon.js`：Canvas角色组件，结合姿势切换与位移、缩放实现动作，非逐帧连续手绘动画。
- `bichon-data.js`：三阶段、逐级体形、12种动作配置。
- `bichon-effects.js`：逐级增加云朵、星光、星桥、流星、光幕、云翼、交织轨道。
- `preview.html`：15级效果与三阶段动作图鉴。

## 游戏接入

游戏入口已加载资源，通过 `game/bichon-character.js` 注册独立蓝色主题、云朵鸡肉丸、互动台词和动作池。正式版300积分兑换；测试版自动加入已解锁角色。喂食500ms，花20积分获得20成长。

Lv.6、Lv.11进化，1–15级体形逐级增长，背景每级保留已有元素并增加一层。15级之后继续升级但保持最终外观。升级使用共用的暗背景全屏展示。
