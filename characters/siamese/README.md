# 暹罗猫角色包

完整的三阶段游戏角色，使用透明 PNG 动作素材、Canvas 动画组件和逐级累积的 SVG 背景特效。

## 成长阶段

- Lv.1–5「暹罗幼猫」：呆萌好奇，莲铃与小蝴蝶结构成早期识别点。
- Lv.6–10「兰纳灵猫」：体态更修长，加入青绿、皇家紫泰丝与兰纳金饰。
- Lv.11–15「暹光守护者」：成年优雅体态，完整泰式金饰、莲台和王庭光阵。

Lv.6 与 Lv.11 会进化并更换角色素材。Lv.1–15 每一级都会放大体形并增加一层可见背景特效；Lv.15 后仍可升级，外观沿用 Lv.15。

## 动作

九张核心姿势覆盖待机、眨眼、招手、蹭手、进食、思考、睡觉、跳跃和技能。组件组合这些姿势提供 `idle`、`wave`、`pet`、`feed`、`think`、`comfort`、`celebrate`、`jump`、`sleep`、`run`、`skill`、`evolve` 动作。

喂食动画固定 500ms。点击角色会从互动动作池随机选择；待机时会随机思考、招手、睡觉或蹭手。

## 游戏配置

- 兑换：300 积分
- 食物：椰香芒果饭
- 每次喂食：消耗 20 积分，增加 20 成长值
- 场景：兰纳花园 · 莲灯回廊

打开 [动作与成长预览](preview.html) 或游戏测试版 `../../index.html?test=1` 查看完整效果。

重新切图与构建素材：在仓库根目录运行 `node scripts/build-siamese.cjs`。
