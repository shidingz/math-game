# 萨摩耶：戴眼镜的小学霸

雪团幼犬（Lv.1–5）→ 踏雪伙伴（Lv.6–10）→ 霜辉守护者（Lv.11+）。
白色蓬松毛发、圆脸、黑亮眼睛、半透明方圆眼镜贯穿三个阶段；招牌互动是抬爪扶眼镜。

## 文件

- `assets/stage-N.png`：三套 1536×1536 RGBA 九宫格动作图集。
- `assets/stage-N-{idle,blink,wave,pet,feed,think,sleep,jump,skill}.png`：27 张透明姿势图，每张512×512；统一脚底锚点(256,470)。
- `assets/stage-N-portrait.png`：三个头像。
- `assets/effects/level-01.svg` 至 `level-15.svg`：可独立使用的15套动画背景。
- `samoyed-data.js`：动作、阶段、每级体形与特效配置。
- `samoyed-effects.js`：15级逐层叠加的可缩放SVG特效。
- `samoyed.js`：Canvas Web Component；高DPI画布、姿势切换与程序位移，不是骨骼动画。
- `../../game/samoyed-character.js`：角色注册、冰蓝主题、食物和随机台词。
- `preview.html`：全部15级特效与三阶段动作静态预览。

## 动作与成长

待机呼吸、眨眼；随机扶眼镜、招呼、蹭手、小憩。点击随机招呼、思考、蹦跳、蹭手、庆祝或展示本领，并避免连续重复。
食物为酸奶雪团，20积分换20成长值，三个阶段喂食均为0.5秒。兑换角色花费300积分，测试版自动解锁。
累计将30/80/150道答对题目的积分用于喂养，可到Lv.6/11/15，角色兑换费用另计。Lv.15后继续每300成长值升一级，外观与特效保留Lv.15。
每级体形增加，进化前后保持递增；三个阶段采用相同展示倍率。
升级使用现有全屏暗背景成长展示。未修改其他宠物的特效。

## 15级特效

每级保留已经获得的背景层，并新增实质图形；不是仅改颜色或透明度。

1. 雪绒初光：蓝色光晕、八点星雪。
2. 六角飞雪：新增六枚旋转雪花。
3. 冰晶萌芽：新增四枚双面冰晶。
4. 雪爪涟漪：新增双层脚下光环与星点。
5. 星雪轨道：新增环形轨道与十枚星芒。
6. 踏雪觉醒：新增六角雪阵与霜冠。
7. 霜羽回旋：新增六束对称霜羽。
8. 智慧星图：新增连线星座与八枚节点。
9. 流星冰雨：新增四道流星、六枚环绕冰晶。
10. 极光帷幕：新增蓝紫渐变极光。
11. 霜辉觉醒：新增十二瓣旋转法阵与光环。
12. 晶塔守护：新增六座大型冰晶塔。
13. 星轨共鸣：新增交错双星轨和流光。
14. 天穹雪翼：新增三层对称雪翼。
15. 极光星雪领域：新增领域双环、王冠星阵和星雪瀑布。

动态包含慢速轨道旋转、上下漂浮、流星下落；暂停、后台和减少动态效果设置均受支持。特效绘制在人物后方。

## 生成来源

使用内置 ImageGen；概念稿与生成提示词保存在工作区 `output/samoyed/`。
原始透明请求得到带棋盘背景的RGB图片，因此由ImageGen重新生成纯色素材底，再通过 `scripts/build-samoyed.cjs` 的项目图集构建流程抠除素材底、提取连通角色并对齐。游戏只引用构建后的真实RGBA透明图像。
