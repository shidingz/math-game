# 算算萌宠 · 微信小游戏

这是原生 Canvas 微信小游戏工程。`game.js` 是入口，无 HTML / DOM / Web Component 依赖。保留工程已有 AppID，使用微信开发者工具打开本文件所在目录即可编译预览。

## 已接入

- 幼儿园至六年级、均衡或指定题型、精确小数/分数判定、错题回顾。
- 每轮 10 题，答对 +10 积分，400ms 后继续；答错显示答案后手动继续。
- 首次免费任选一只，其他伙伴每只 200 积分兑换；8 只伙伴独立成长。
- 20 积分换 20 成长值，喂食 500ms，手机双列操作，脚下反馈，全屏升级。
- 8 个原角色、每个角色三阶段、全部姿势帧；Canvas 适配的随机互动和逐级光效。
- 各宠物独立素材分包，失败可重试，切角色释放旧图，DPR 上限 2，后台停止动画与延迟计时。
- 微信本地存档、旧版本载荷迁移与 retiredPets 保留。网页浏览器存档不会自动迁入。
- 「换伙伴 → 拍照 / 上传」可保存多次制作记录；每次完成任务得到独立自定义伙伴。固定三阶段九宫格素材包由共享播放器加载，无需为每只宠物生成代码，列表支持分页。

## 使用

1. 用微信开发者工具打开工程，保持项目类型为“小游戏”。
2. 点击编译，首次进入选择宠物；选择年级后开始做题。
3. 点击“预览”，用真实 iOS 和 Android 设备测试。角色分包第一次加载需网络。
4. 主包、分包的导出统计见 `wechat-build.json`；最终上传包体以开发者工具为准。

当前不含已部署的生成服务、云成长存档、广告、支付或排行榜。可配置生成服务接口，使用 wx.login 换取服务端会话；默认接口为空，只保存本机照片草稿，不会调用生图。分数与存档在客户端维护。

## 正式与测试

正式构建 `config.js` 中 `debug:false`，不接受 query 的测试开关。
开发人员使用 `build:wechat -- --test` 生成独立测试构建，并在编译条件中设置 `test=1`。加上 `--test-default` 可制作打开即进入测试模式的独立工程；`test=0` 可在该构建核对正式规则。所有测试构建仍拒绝在 `release` 环境开启调试。测试模式显示无限积分，喂养和兑换不扣分，自动拥有现有与新增本地宠物，主页提供测试等级工具。存档使用单独的测试键，重新打开保留成长；正式版仍按20积分喂养、200积分兑换，不向正式存档赠送积分或宠物。

本地存储键：正式 `math-pet-wechat:formal:v1`，测试 `math-pet-wechat:test:v1`。读取失败时不会覆盖无法读取的旧存档。清理微信小游戏数据或更换设备不能自动恢复；当前没有跨端同步。

## 从 math-game 更新

微信实现源文件在 `math-game/wechat/`，交易与题库源文件在 `math-game/game/`。请在源仓库修改，导出时会逐字复制纯逻辑并记录 SHA-256，避免两套规则漂移。

```sh
# 微信导出额外需要 sharp；原网页的 test / check / build 仍无第三方依赖。
npm install --no-save --package-lock=false sharp
npm run build:wechat -- --out /path/to/staging --config /path/to/minigame-1/project.config.json
# 生成服务上线后，追加 --custom-pets /path/to/public-custom-pets.json
```

先生成到空的暂存目录，验收后将 `game.js`、`game.json`、`config.js`、`runtime/`、`shared/`、`data/`、`portraits/`、`pets/` 及导出配置同步到微信工程。保留原来的 `project.private.config.json`。导出器拒绝直接覆盖没有构建标记的已有工程。不要将网页完整素材、编辑单帧、测试截图放入上传包。

`preview.html` / `preview.js` 是浏览器验证适配器，在开发者工具上传配置中已排除。它能检查绘制、触摸与流程，但不能替代微信真机和分包下载验收。美术图集沿用原稿，经 384px 帧尺寸和透明调色板压缩；光效是 Canvas 版本，未直接复用网页 SVG/CSS。

自定义宠物的素材规范、通用 `pack:pet` 命令及接口响应示例见源码仓库 `docs/CUSTOM-PETS.md`；公开配置示例为 `wechat/custom-pets.example.json`。相机/相册权限、隐私声明、上传和下载域名需要在实际微信环境联调。生成完成通过前台轮询/下次打开同步，不代表退出后的消息推送。

## 发布前验收

真实 iOS / Android：免费领养、兑换扣分、低网速分包、各角色所有阶段、500ms 喂食、全屏升级、前后台恢复、退出重进、小数与分数键盘、错误手动继续、连续答题不重复奖励、15 级后升级。发布前使用正式构建，按公众平台实际类目完成适用资料、备案及审核要求。本工程的完成不代表已通过微信审核或发布。
